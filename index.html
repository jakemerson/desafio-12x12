A Filosofia do Desafio

01. Velocidade e Foco

Eliminar o perfeccionismo paralisante. Cada ferramenta é limitada a um escopo enxuto que resolve uma dor clara em até 7 dias.

02. Privacidade Local

Prioridade para arquitetura Local-First. Dados do usuário ficam na máquina dele sempre que tecnicamente possível.

03. Open Source

Todo o código fonte, planejamento e decisões de arquitetura ficam públicos no GitHub para consulta e contribuição da comunidade.
