## 🎯 O Desafio

O **Desafio 12x12** é um compromisso público de engenharia de software e criação de produtos digitais:
Construir, validar e lançar publicamente **1 projeto completo por semana durante 12 semanas consecutivas**.

Cada projeto deve resolver uma dor real, ser utilizável por pessoas reais, ter código aberto e deploy em produção.

## ⚡ Princípios do Desafio

1. **Ship Fast:** O produto precisa estar no ar em 7 dias. Sem overengineering desnecessário.
2. **Local-First & Privacidade:** Processamento no cliente sempre que viável, sem armazenar dados sensíveis de usuários.
3. **Qualidade Visual & DX:** Interfaces limpas, responsivas, com atalhos de teclado e feedback imediato.
4. **Open Source & Transparência:** Todo código, decisões de arquitetura e roadmap documentados via metodologia GSD.
